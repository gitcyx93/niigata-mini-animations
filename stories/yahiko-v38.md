# 弥彦 V38：两段风与有声首尾循环

入口：`viz/autumn/yahiko-v38.html`。27.8 秒，音频时钟驱动，默认循环；需点击“有声播放”启用声音。

## 英文與繁體社交發布版

- 已移除參考配樂；發布用 `master.wav` 與純音效 `effects.wav` 完全相同。
- 原 CC0 遠處鳥鳴分軌延續到溫泉街 21.6、22.7、25.1、26.25 秒，音量較日間克制並避開貓叫。未確認鳥種，不把聽感當成物種鑑定。
- `viz/autumn/yahiko-v38-en.html`：英文字幕；`viz/autumn/yahiko-v38-tw.html`：臺灣繁體用語與嵌入的繁體字形字體。
- 發布 MP4、規格與署名：`output/autumn/yahiko-v38-social/`。兩版共用相同無配樂音軌；錄製、解碼與文字檢查結果由 `exports.json` 記錄。
- 本機構建：`NODE_PATH=/path/to/font-and-opencc/node_modules node viz/tools/build-yahiko-v38-locales.cjs`；匯出：`PLAYWRIGHT_MODULE=/path/to/playwright FFMPEG=/path/to/ffmpeg node viz/tools/record-yahiko-v38-social.cjs`。
- 預覽伺服器提供 `/en`、`/tw`；已存在的成品預設不覆蓋，重新匯出須明確加 `--force`。

## 合入 main 前的最后修订

- 12.8–17.1 秒原“海景声”经源清单核对实际是开阔地风。只替换这段底轨为 Luftrum 的海浪录音，经滤波、减小音量和淡化做远景氛围；授权署名已补齐。未声称已证明原素材存在编码失真。
- 其他已认可音效不动；伴奏增益冻结，不再因海景电平变化重新归一化音乐。
- 移除标题积叶、字中停留及贴字脱落，保留场景中的两段主叶动态与首尾衔接。
- 标题改为暖白—浅铜的秋色材质，减弱硬浮雕与镜面亮度，暖色漫反射随同一场景风力轻变。旁白、字幕内容和字号不动。
- README 的当前秋季入口更新为 V38；历史视频仍保留，不冒充 V38 导出。

## 前次试听修订

- 已撤回约4秒整段降噪，恢复旧底轨；页面提供原底轨3–6秒、神社风铃、神社树林风分轨，全部保留实际混音增益供定位。
- 神社风铃换为 Esc861 的公共领域 `Windchimes.ogg`，3.3–8.65秒一次播放完整自然连响，不重复单声采样。
- 标题叶片逐片松动，错峰落到文字中部停留，再继续落下；保持片尾到开场的积叶状态连续。
- 新增可关闭的原创合成轻钢琴／暖氛围参考小样，约69 BPM；无鼓、无人声、无第三方歌曲采样。音乐平均电平比音效低约7.67dB，并在关键音效时轻度压低。不是专业LUFS母带声明。
- `master.wav` 为带参考音乐混音，`effects.wav` 为纯音效，`music.wav` 为音乐分轨。页面可开关伴奏、单听音乐；后续用户上传时可替换同风格曲目。

以下是基础V38与前次修订记录；冲突处以本节为准。

## 画面

- 合入红叶谷点灯段与温泉街片尾两处风的动态。枝梢先偏转、少量叶子脱落、近景主叶翻面掠过；标题边缘叶片也在风来时飞离。
- 片尾主叶飞行延长至下一轮开场。温泉街使用 `a=t-24.4`，开场使用 `a=t+3.4`；切点两侧继续同一轨迹、大小、翻面角度与透明度，不重置随机状态。
- 保留满屏温泉街硬切开场、等尺寸太阳；小字优先清楚，左上恢复 500 字重。隐藏历史对照按钮。
- 近景折面叶片使用高分辨率缓存，降低密集飞叶数量，去掉空中叶片的模糊投影。

## 声音

- 复用 V25 的 B 版（环境音、鸟鸣、风叶、风铃、温泉细水），由 24.6 秒延长到 27.8 秒。尾段补原有静场与细水，不重复风铃敲击。
- 两处风叶声：17.45 秒、25.8 秒；后者跨过循环边界继续至开场。
- 23.45 秒猫的 `ニャッ` 动作处加入 Mike Koenig 的实录 Kitten Meow，截取 1.25 秒、降低音量、稍偏右。
- 9.8 秒轻加已有索道低鸣；不添加音乐或脚步声。
- 混音为 32kHz / 16bit / stereo WAV；来源、裁剪和授权在 `viz/autumn/audio/yahiko-v38/`。猫叫和索道均需署名，页面已提供署名与授权入口。

## 本轮微调

- 3.0–5.2 秒旧底音平滑压低，以安静环境声补齐，针对用户指出的约 4 秒杂声；没有抬高其他声音去盖噪音。
- 3.2–9.9 秒神社段连续轻风铃尾音＋树林风；左上文字和其他已确认画面不改。
- 窗框拟音复用公共领域木门绞响，经滤波、削弱后按 `townWindowState` 的左右窗扇角速度调制音量，不使用与动作无关的机械定时声。
- 标题开场已有 11 片积叶，随开场风分批离开；片尾重新积回相同位置、姿态与透明度，首尾检查覆盖全部 11 片。
- 本轮经验与以后默认流程见 `docs/YAHIKO_ITERATION.md`。
