# 冬：越后汤泽 · 独立新稿「从云上滑进温泉」

页面 `viz/winter/yuzawa-claude.html`（24 秒循环，1080×1920，无声）。与正式版 `yuzawa-yukiguni.html` 无关，没有改动正式版。

## 想法

一张竖着的长画卷，山顶在上、温泉在下，镜头只上下移动，一镜到底；光线跟着故事变。

| 时间 | 画面 | 大字 |
|---|---|---|
| 0–3.6 | 第 0 帧新干线已在画面里减速进站、卷起雪（阴天飘雪） | 66 分钟到雪国（第 0 帧就在，当封面） |
| 3.6–8.4 | 车站多停一会儿再沿缆车上山，穿过薄云 | 出站就是雪场（3.45–5.3，车站还在画面里） |
| 8.4–10.7 | 山顶：云海、晚霞、树的长影 | 10 米的雪 |
| 10.7–16.3 | 一出发镜头就推近到约 1.8 倍跟着人滑，转弯轻微侧倾和抖动；15–15.8 拉回全景，人刹停在坡脚的人群旁 | 天黑前 最后一趟（12–14.6） |
| 16.3–21.4 | 镜头继续落到夜里的露天温泉，18.3 秒起慢推向泡汤的两个人 | 滑完雪 泡温泉 |
| 21.4–24 | 提醒；温泉直切回第 0 帧的车站 | 想人少 3 月去 |

## 做法

- 世界按「中性白天」预先画成一张长图；每帧整体乘一层随时间变化的色调，夕阳长影是另一张图，灯光最后叠加。
- 文字层、标题、字体沿用 `viz/common/series.js`；改字后重跑 `python3 viz/tools/embed-font.py viz/winter/yuzawa-claude.html`。
- 页面暴露 `PLAN` 和 `inspectAt(t)`，可用 `viz/tools/inspect-animation.cjs` 检查。

## 事实（2026-11-12 查）

- 降雪累计 1054 cm、最深积雪 208 cm（1991–2020 平年值）：气象厅汤泽站页面，已打开确认。
- 「东京（上越新干线）最短 66 分」：汤泽町观光まちづくり机构 https://www.e-yuzawa.gr.jp/ 。未找到 JR 原文。
- 「ガーラ湯沢駅直結…改札を出れば目の前に広がる白銀のゲレンデ」：https://gala.co.jp/winter/ 。同页写东京到 GALA 最速 71 分，所以画面上 66 分钟标的是「东京 → 越后汤泽」。
- 「3 月外国游客比 1、2 月少」沿用 `data/SOURCES.md` 的旧数据，月度原表仍未核。
- 画面是示意：GALA 的缆车、下山雪道、温泉的位置关系没有按实地画；傍晚滑回山脚是压缩后的叙事，不代表实际营业时间。

## 2026-11-13 修改（在 Fable 稿上）

- 开头和回环：去掉首尾的雪雾，温泉直切回车站（用户此前已否定过雪雾遮挡的转场）。第 0 帧就有车头、标题和「66」。
- 穿云：整屏铺色的雾从 .8 降到 .3，峰值从 .95 降到 .55，不再白屏。
- 数字：「66」「10」字重 200→400、字号 140→156，白天的强调色加深。
- 推镜：`zoomAt(t)` / `applyZoom()` 把画面（不含文字）以主体为中心放大；`inspectAt` 增加 `zoom`，人物的屏幕坐标为缩放后的值。
- 空间：车站门口的人挪到坡脚的雪上，滑雪终点 `SKI1` 5120→5030，人不再停在屋顶；左侧行灯挪开，不压大字。
- 温泉：夜色改成冷蓝 `[96,106,152]`，池子周围的暖光 .3→.12，石头不再整圈发粉；水面另铺一层深青色、不吃整体色调，泡汤的人画在水面之上。
