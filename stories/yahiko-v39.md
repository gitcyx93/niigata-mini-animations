# 弥彦 V39 试作：只改画面，不动时间轴与声音

入口：`viz/autumn/yahiko-v39.html`（由 V38 简体页复制后直接修改）。27.8 秒，镜头切点、旁白与文案内容、`audio/yahiko-v38/master.wav` 全部沿用 V38。V38 仍是已认可版本，本页是给用户看的试作，尚未经用户确认。

## 本轮实改

- 去掉日落处的「ストン」拟声字；猫的「！」「ニャッ」保留。
- 月亮：改从画面右侧海面升起，停在右上（约 840–900, 300–335），不再穿过旁白，也不再贴着标题。
- 中下方大字：强调色由 `#f4c586` 提亮为 `#ffdca6`，深色光晕叠两次，并用一团柔和暗晕压暗字后的景物（不垫色带）。字号、字重、位置不变。
- 海景（13.0–17.0 秒）：镜头向右摇约 216px，太阳移到画面中部，佐渡岛重画为两段相连的山脊并完整入画，离开右侧按钮列。前景山坡放大 1.23 倍以提供摇镜余量。
- 鸟居：推进幅度由每源秒 1.4% 提到 5%，朝参道尽头的拜殿靠近。
- 夜景右上角横枝提亮（效果有限，叶簇仍略显悬空）。

## 没做的

- 没有重排时长、没有把夜景前置为封面：两者都要重剪已认可的声音。
- 杉树干、针叶林的重复感，近景大叶的折纸感，片尾文字与足汤人物的轻微重叠，均未处理。
- 繁体、英文页未同步。

全片 834 帧逐帧渲染导出，无脚本错误；抽看了各镜头关键帧与海景—月升连续帧。未做人耳试听，未在平台实机 UI 下检查遮挡。
