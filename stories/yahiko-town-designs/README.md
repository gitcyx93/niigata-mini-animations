# 温泉小镇静态设计（2026-11-05，构图草稿）

参考 `reference/yahiko-town-reference/`。三张都是入夜、月亮在左上，叠上了现在的片尾文字看位置。只定构图方向，细节等选定一张再画。生成：在 `viz/autumn/yahiko-v24.html` 里加载 `designs.js`，调 `designA/B/C`。

- A｜从一之鸟居里往外看（参考 1）：鸟居和两边大树框住画面，石阶下去是门前街，两边店铺亮着，电线杆、路灯，街一直伸到远山；月亮在鸟居开口里。动起来：慢慢穿过鸟居往街上推。
- B｜神社旁的土产店，斜着看（参考 2）：一排两层木造店，二楼木格栅，一楼亮着，彩色遮阳棚、のぼり旗、红毛毡长凳和野点伞、「名物」招牌；后面是神社的杉林和月亮。动起来：沿店面横移。
- C｜从弥彦山上往下看（参考 4）：近处是山坡的红叶和一棵枝干伸出来的树，山脚一簇暖灯是温泉小镇（旁边一块暗的是神社的林子，有很小的红鸟居和几缕热气），再往外是越后平原星星点点的村落灯和路灯线，远山，月光下的薄雾。动起来：慢慢往下摇或往前推。
