# 弥彦 V40 试作：夜景开场、重排时间轴（无声）

入口：`viz/autumn/yahiko-v40.html`，28.8 秒，无声自循环，可单独打开。在 V39 试作上继续改；用户本轮指示「不管声音、只要 HTML、最大自由度」。V38 仍是已认可的有声版本，本页尚未经用户确认。

## 时间轴

| 秒 | 镜头 | 说明 |
|---|---|---|
| 0–3.2 | 亮灯的红叶谷（封面） | 新开场：宽取景、持续慢推；大字「上山看海 入夜看秋」 |
| 3.2–6.4 | 一之鸟居 | 同 V39 |

| 21.6–28.8 | 温泉街 | 内容同 V38（旧时钟 20.6–27.8） |

- 去掉了地图全景镜头；它的旁白「红叶最好看在 11 月上中旬。」移到开场。
- 实现方式：`render(N)` 把新时间 N 映射到旧时钟 t（N<21.6 时 t=N，之后 t=N−1），各镜头原画法不变；开场与夜景延长段直接调用红叶谷画法。字幕按新时间轴排在 `titlesC(N,t)` 和 `STORY_N`。
- 首尾：温泉街结尾的大叶与飞叶延续到开场的红叶谷，轨迹连续。
