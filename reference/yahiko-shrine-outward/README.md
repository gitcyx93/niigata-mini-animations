# 从弥彦神社向外看：只选两张摄影参考

需求：少而精，以神社入口向门前街道看出去的视角为主，用于动画布景，不做照片发布。原图保存于本地 `Documents/niigata-reference/yahiko-shrine-outward/`；此目录仅保存来源及构图笔记。

## 1. 主参考：从一之鸟居内侧向外看门前街道

- [直接查看照片（1200×800）](https://niigata-kankou.or.jp/lsc/upfile/blog/0000/1414/1414_1_l.webp)
- [来源：新潟县观光协会「たびきち」，井高あゆみ，2026-03-16 发布](https://niigata-kankou.or.jp/blog/detail_1414.html)
- 本地：`01-torii-looking-out.webp`。

**这张符合要求的方向。** 画面从境内侧透过一之鸟居，向外看石阶、横穿入口的道路与对面的门前街道；不是从街上朝神社拍，也不是村外的巨大公路鸟居。

布景参考：
- 前景：阴影中的树干、鸟居、石栏与台阶，形成完整的画框。
- 中景：门外横向道路、白色标线，连接正对入口向前延伸的街道。
- 远景：店屋、路灯、电线杆逐渐缩小，远处低山色调变淡。
- 最有价值的是“暗的神社树林 → 明亮的小镇”的层次。做插画时可以简化电线与杂物，但应保留门口横路、街道纵深和建筑高度差。
- 照片逆光较重，不能直接按暗部颜色推定鸟居实际颜色；它也不是秋季色彩参考。未核定精确拍摄站位或日期。

## 2. 辅助参考：神社旁土产店街的店面与纵深

- [直接查看照片（1920×1279）](https://static.gltjp.com/glt/data/article/21000/20897/20250106_155530_3e75d42f_w1920.webp)
- [来源：GOOD LUCK TRIP「彌彦神社の観光ガイド」，食べ歩き段落](https://www.gltjp.com/ja/article/item/20897/)
- 本地：`02-shops-beside-shrine.webp`。

**这是补充店铺立面的侧向街景，不是第 1 张同机位向外的延续。** 可见西澤商店、棚桥商店一带的木格栅、坡屋顶、彩色遮阳棚、暖帘与橱窗。

布景参考：
- 一侧是树林与石栏，另一侧是连续但高低不一的店屋。
- 木色、白墙、深色屋顶是主色，遮阳棚和店旗提供少量亮色。
- 店铺是有深度的空间：屋檐阴影、格栅、门窗、檐下陈列分层，不宜只画成发光方块。
- 用它补第 1 张里较远、看不清的店面结构，不把两个方向强行拼成同一条正前方街道。拍摄日期未核定。

两张均已打开检查，不再加入方向不符的鸟居正面照、山顶平野照或泛泛地图。未修改任何动画与字幕。
