# Niigata Mini Animations

以新潟四季旅游场景为主题，用网页绘制的短动画。每集保留独立的 HTML 作品和制作记录。

## 春｜高田夜樱

[动画 v2](viz/spring/takada-yozakura-v2.html) · [制作记录](stories/takada.md)

- **镜头设计（20 秒）**：三重橹近景 → 极乐桥与水中灯影 → 樱花树下仰望 → 花吹雪落入护城河、铺成花筏。
- **画面设计**：以观光协会照片为构图参考。三重橹强调白墙、深灰瓦与草坡上的绿光；极乐桥用侧向透视连接桥身与倒影；樱花按枝干、枝梢与五瓣花绘制。
- **试过的方案**：单一全景从头推拉到尾太单调；团块状樱花显得粗糙；末段重复开头全景也削弱高潮。后来把开头换成建筑近景，保留末尾花瓣落水、镜头拉远的全景高潮。

## 夏｜长冈花火

[动画](viz/summer/nagaoka-hanabi-a.html) · [制作记录](stories/nagaoka.md)

- **镜头设计（20 秒循环）**：信浓川、长生桥和观众剪影作为舞台；开场烟花 → 正三尺玉 → 两波凤凰烟花 → PHOENIX 展翅高潮 → 余晖中的观览提醒。
- **动效区分**：正三尺玉用快速推镜、强烈震动与直径标尺表现冲击力；PHOENIX 改用舒展的推拉，不震动。
- **文字设计**：系列标题使用哑光银、倒角和浮雕效果，字面映出烟花光。

## 秋｜弥彦红叶

[动画 V38](viz/autumn/yahiko-v38.html) · [V38 制作记录](stories/yahiko-v38.md) · [温泉街绘制案例 v25](stories/yahiko-v25.md)

- **镜头与循环（27.8 秒）**：红叶谷、神社与温泉街等场景中安排两段风；枝梢先动，少量叶片脱落，近景主叶翻面飞过。片尾主叶延续到下一轮开场，保持轨迹、大小、翻面角度和透明度连续。
- **手绘场景**：温泉街曾尝试直接把生成图贴成背景，效果不被采用。之后只参考其坡路、旅馆、商铺和庭院布局，用原有 Canvas 树木、木构建筑、夜空与光晕重新绘制。
- **声音设计**：按镜头动作组织树林风、风铃、鸟鸣、远景海浪、风叶、细水、猫叫与窗框声；窗框声随窗扇运动变化。V38 使用环境音，不加配乐。

## 冬｜越后汤泽

[动画](viz/winter/yuzawa-yukiguni.html) · [制作记录](stories/yuzawa.md) · [三维滑雪试作](stories/yuzawa-ski3d.md)

- **镜头设计（20 秒循环）**：新干线出隧道 → 滑雪刻滑、直滑与横刹 → 雪中露天温泉 → 拉远到雪国全景，再回到隧道衔接开场。
- **取舍**：曾尝试 2.5D 一镜到底和飞雪遮挡转场，前者焦点太乱，后者过于刻意，改用直切。滑雪镜头后来尝试以 Three.js 绘制三维坡面、雪树和人物，保留原有动作时序。
- **视觉设计**：标题横笔积雪，关闭字面反射；文字色彩随故事从雪夜冷蓝转到温泉暖色，循环前回到冷色。
