# 新潟动画：已确认经验与快改流程

## 修改原则

- 先确认本轮需要修改的部分；其余已认可的画面、文字、镜头和声音保持不变。
- 沿用当前分支、已批准版本和现有素材，不用旧流程覆盖独立版本。
- 默认不做历史对照；需要比较两套方案时，只改变指定变量，避免其他内容干扰判断。

## 画面与动态

- 文字以清楚易读为先；字体层次与场景光影相协调，不靠大面积模糊阴影或过低透明度制造质感。
- 动态要有自然的先后关系。近景落叶注意折面、正反面、透视和受光；远景可以简化，避免用大量粒子代替真实运动。
- 物体与文字发生接触时，需要符合实际接触关系，不能仅靠任意坐标停靠。
- 循环动画检查首尾关键元素的位置、大小、旋转、形态及透明度，不能只看整体颜色是否接近。

## 声音

- 复用已认可的环境音与分轨，不因局部调整重新改变整片声音的相对大小。
- 不确定某段噪声来源时，先提供同音量分轨试听，再决定调整对象。
- 音效应与动作对应；延续到新场景或跨循环边界时注意时间连续性，避免机械重复。
- 新素材优先选择来源和授权可核实的录音；拟音要如实标注，保留来源与署名。

## 检查与交付

- 优先提供当前可播放的 HTTP 预览链接，让用户直接看或听。
- 快速语法检查加一项针对本轮修改的检查；声音看对应时段及峰值，循环看边界状态。
- 如实说明实际修改、已检查与尚未检查的内容，不把自动数值检查说成主观听审或视觉认可。
- 避免额外方案、重复的历史比较与冗长说明。
