# 新潟动画：已确认经验与快改流程

## 每轮默认流程

1. 先列出用户要求改的几处；“别的不错”意味着其余冻结，不顺手重排字体或换镜头。
2. 沿用当前分支、已批准版本和分轨，只做对应修改。大方案才另开分支，不覆盖认可版本。
3. 先交可播放的 HTTP 链接，让用户看/听；不要只给源码、文件路径或自动打开浏览器。
4. 默认不做历史对照。用户明确要两套方案时，一个页面同屏，仅改变指定变量；文字不能混入动态方案对比。
5. 快速语法检查＋一个针对本次改动的检查即可。声音检查时长、峰值和所改时段；循环检查边界状态。不默认跑全片截图、反复性能基准或导出视频。
6. 明确尚未听审、未导出或未推送的内容，不把数值检查写成已听过。发布时保留素材授权与署名。

## 文字与标题

- 用户最终优先清楚，而不是追求极细。V38 补充文字 40px / 500、左上旁白 44px / 500（1080 宽画布）；暖白、不要用大模糊阴影或低透明度制造“精致”。
- 左上旁白已获认可，不主动改它。片尾保留下移、左对齐的位置。
- 花火的特色来自“字面接住场景的光”，不是只换字体。弥彦保留系列字形和轻微场景映光，不堆满装饰。
- 标题积叶与字中停留试作被用户指出不真实：任意坐标停靠不等于真实接触/碰撞，继续加叶片不能补救。本轮已撤掉贴字叶片，改为暖白—浅铜秋色、弱映光随场景风力变化；真实近景叶片留在场景中。以后若重做文字接触，需要先解决字形与叶片的接触逻辑，不把失败试作当成永远禁止落叶。

- 2026-11-11 用户明确：中下方大字是极简风格，**不加字影或光晕**；下面的小字只是补充，字号、字重要明显小于大字（V41：大字 68px/300，小字 30px/400）。人物剪影不要纯黑实色。

- 2026-11-11 用户明确：不要改镜头顺序、不要另做转场。原设计以太阳、月亮为主线，转场是把前一个场景的元素（叶子、日月）接着用到下一个场景；新增内容必须放进这个结构里。

## 落叶与动态

- 先静、树梢先动、少量叶子脱离、一片近景主叶翻面掠过、叶子让开露出景物。比全屏同时喷出大量叶子更有记忆点。
- 可辨认的近景叶需有折面、正反面、透视及受光；不只旋转压扁同一张图。远景可以轻量贴图。
- 空中叶片不要统一挂模糊投影；高清姿态缓存减少逐帧重复计算。数量克制，不以“更多粒子”代替物理感。
- 首尾硬切，不再缩成圆窗。共同时间轴跨 27.8→0 秒；检查位置、大小、旋转、折面、透明度，而不只检查画面颜色相似。
- 保留场景主叶的首尾状态连续；当前不再有标题积叶，不能为凑循环重新把已撤掉的贴字叶片加回去。

## 音效

- 默认从用户选定的 V25 B 版继续：环境音、鸟鸣、风叶、风铃、细水。不要每轮重新归一化整片、改变已认可声音的相对大小。
- 用户指出某秒太吵但不确定声音来源时：先保留/恢复原声，给时间表与同音量分轨试听，让用户确认是哪一层；不要自行压掉或替换整段。约4秒的处理已撤回，提供原底轨3–6秒、风铃、树林风三条试听。
- “一阵风吹过叮铃铃”需要一整段自然多次连响实录，不是同一铃声重复采样。当前神社风铃使用 Esc861 的公共领域 Windchimes.ogg，3.3–8.65秒只播放一次；下方铺轻树林风。
- 猫叫对齐 23.45 秒 `ニャッ` 动作。窗框声由窗扇角速度驱动，停住就安静，不在整段温泉街持续制造噪声。
- 风叶尾音跨循环边界；环境延长不重复风铃敲击。
- 先复用已批准分轨；必须找新素材时，选可确认授权的实录，保存原件与来源。门响用于窗框时写明是拟音，不冒称实地录音。
- 海景的声音先查素材类型和听觉距离：原段实际上是开阔地风声，不是海浪。更换时只替换对应区间，以低电平、适当滤波和交叉淡化控制距离感；不要把“用户说音质差”直接写成已证实编码失真。
- 用户要求音乐参考时，保留独立纯音效版和音乐开关。先试无鼓、无人声、稀疏轻钢琴／暖氛围，约60–75 BPM；按音效相对电平配低，关键音效时略压音乐。合成参考样必须明确说明，不冒充实录钢琴或已有歌曲。
- 当前原料与重建入口：`viz/tools/build-yahiko-v38-audio.cjs`、`viz/autumn/audio/yahiko-v38/LICENSES.md`。始终按最新视觉代码取窗扇运动数据。

## 今天的定稿、翻譯與發布經驗

- 使用者確認後凍結畫面、字幕位置和已認可聲音；發布版本不再拿新方案試驗。取消配樂要同時處理音頻母帶、播放器與匯出來源，不能只是把某個預覽按鈕關掉。
- 音效表要包括森林底軌裡隱含的鳥聲，不只列單獨加入的提示音。延續到新場景時優先用原分軌、稀疏放置並避開貓叫；未確認鳥種時不把「布谷般」的聽感寫成已核實物種。
- 英文不是逐字替換：縮短句子保持原意，單獨調整字距、標題大小和句寬，不縮放整幅畫面。地名保留 Yahiko、Momijidani、Kangetsukyo 等識別資訊。
- 繁體使用 OpenCC 臺灣詞彙與真正的繁體字形字體，重新嵌入所需字庫，檢查「彌彥」「纜車」「公尺」等字形；不要讓簡體子集字體靠系統字體碰運氣。
- 正式發布才做必要的逐幀匯出、文字邊界檢查、關鍵畫面檢視及全片解碼。網頁用 requestAnimationFrame 即時錄螢幕可能丟幀；固定 30fps、每幀呼叫 render(t) 更可靠。
- 兩種語言共用同一份無配樂聲音母帶。預設交付 H.264/AAC、1080×1920、30fps、yuv420p、BT.709、fast-start MP4；匯出記錄保留來源及成品雜湊。
- 保留發布署名文件；使用者上傳到平台時查看實機 UI 遮擋，不能把網頁畫布檢查等同於平台最終顯示。
- 重用已有 FFmpeg、Playwright、OpenCC、Fontsource 安裝，不為定稿重新搭建一套工具鏈。新潟本機現有可用依賴位置記在任務記錄或環境變數，不硬編進發布頁面。
