# 弥彦 V38 · 制作记录与技术入口

2026-11-10 已撤销旧的 AI 改动限制与固定流程。本文记录当前作品及既往试作事实，供后续制作参考；画面、字幕、声音、时长和实现均可随当前任务调整。

## 当前画面

V38 当前长 27.8 秒，画布 1080×1920，包含红叶谷、杉林鸟居、拜殿、缆车、山顶海景及温泉街。源码在 `src/yahiko-v38/`，三个语言页面由 `viz/tools/build-yahiko-v38.cjs` 生成。

- 当前补充文字为 40px / 500，左上旁白为 44px / 500；片尾文字下移并左对齐。
- 标题使用暖白至浅铜秋色和轻微场景映光。曾尝试标题积叶与字中停留，因接触位置缺乏真实碰撞依据而撤回。
- 近景叶片使用折面、正反面和受光变化，状态积分和姿态贴图已有缓存。
- 片尾回到开场采用直接切换；当前主叶运动跨 27.8→0 秒边界连续。

## 当前声音

母带由环境音组成，播放器以音频时钟驱动画面。音频配置、素材和授权信息集中在 `viz/autumn/audio/yahiko-v38/`。

| 声音 | 当前处理 |
|---|---|
| 森林底轨 | 延续 V25 B 版，底轨本身含鸟声；约 4 秒的原声曾恢复，并提供分轨试听 |
| 神社风铃 | Esc861 的 Windchimes.ogg，当前使用 3.3–8.65 秒的一段自然连响 |
| 海景 | 轻远海浪替换早期的开阔地风声 |
| 猫叫 | 当前与 23.45 秒动作对齐 |
| 窗框声 | 由窗扇角速度驱动，源素材为门响拟音 |
| 风叶 | 尾音跨循环边界；温泉街另延续原远处鸟鸣 |

`build-config.json` 提供图层开关和增益；`mix.json` 记录当前母带。`npm run build:audio` 生成试听，`--update-release` 可更新发布目录。声音构建读取当前视觉代码中的窗扇运动。

## 语言与导出

英文版有独立的措辞、字号、字距和行宽；繁体版使用台湾词汇及繁体字体子集。当前三语言由 `locales/*.json` 的精确源码替换生成，这一结构可进一步改为独立文本和布局数据。

现有视频导出按固定帧时刻调用 `render(t)`，默认 H.264/AAC、1080×1920、30fps、yuv420p、BT.709 和 fast-start。输出记录包含来源哈希和媒体验证结果。工具用法见 [检查与制作工具](AI_INSPECTION.md)，现有署名见 `output/autumn/yahiko-v38-social/PUBLISHING.md`。
